# PatientPoint — Hospital Appointment & Patient Portal

PatientPoint is a modern, responsive hospital website designed to help patients explore hospitals, find doctors, and navigate appointment-related services through a simple and user-friendly interface.

Features

- Emergency Ambulance Directory: Quick helpline contact numbers for major emergency ambulance services in Karachi.
- Hospital Directory: Explore 29 hospitals in Karachi with links to their official websites and direct Google Maps directions.
- Doctor Directory: Search and filter doctor information and real-time availability by department.
- Appointment Interface: Book appointments with automatic doctor assignment, live side-by-side queue tracking, and printable/downloadable token slips.
- Patient Registration: Pre-visit registration interface with document and report attachment options.
- Token Tracker: Search and view real-time appointment token status and estimated wait times.
- Multi-Language Support: Switch seamlessly between English, Urdu (اردو), and Sindhi (سنڌي) with automatic layout adjustments.
- My Account: LocalStorage-based patient login and registration system.
- Responsive Design: Designed to work across desktop, tablet, and mobile screens.
- Modern Navigation: Easily move between website sections with active state indicators.
